# 📊 Exploratory Data Analysis (EDA) Dashboard

## 📌 Project Overview
This project performs **Exploratory Data Analysis (EDA)** on the cleaned Cola dataset prepared in Week 1.  
The goal is to uncover patterns, trends, and relationships using descriptive statistics and visualizations.

---

## 🛠️ Tools & Libraries
- Google Colab (environment)  
- Python 3.x  
- pandas  
- NumPy  
- Matplotlib  
- Seaborn  

---

## 📂 Project Structure
- `Cola_Cleaned.csv` → Cleaned dataset from Week 1  
- `EDA_Dashboard.ipynb` → Google Colab notebook for analysis  
- `README.md` → Project documentation  
- `screenshots/` → Visualizations and charts  

---

## ⚙️ Setup Instructions
1. Open [Google Colab](https://colab.research.google.com/).  
2. Upload the cleaned dataset (`Cola_Cleaned.csv`).  
3. Open the notebook (`EDA_Dashboard.ipynb`).  
4. Run the cells step by step to generate descriptive statistics and visualizations.  

---

## 📊 Analysis Workflow
1. Load the cleaned dataset.  
2. Perform dataset overview (shape, info, missing values).  
3. Generate descriptive statistics.  
4. Create visualizations:
   - Histogram (distribution)  
   - Boxplot (outliers)  
   - Line plot (trend over years)  
   - Bar chart (category comparison)  
   - Heatmap (correlation matrix)  
5. Document at least **5 key insights**.  

---

## 🔎 Key Observations
- Value distribution is right‑skewed.  
- Year shows steady growth with some decline in later years.  
- Outliers exist in the value column.  
- Certain categories contribute disproportionately.  
- Strong correlation observed between variables.  

---

## ✅ Conclusion
This EDA helped identify important dataset patterns, trends, and correlations.  
The insights will be useful for future analysis and decision‑making.
